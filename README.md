# The Lei Áurea in Akoma Ntoso

Brazil's Law No. 3,353 of May 13, 1888, known as the Lei Áurea or Golden Law, which abolished slavery in Brazil. It is in Akoma Ntoso XML, with a CSS stylesheet that renders it after the manuscript, and was generated by Claude for Grant Vergottini.

## Files

| File | Purpose |
| --- | --- |
| `lei-aurea.xml` | The Akoma Ntoso document |
| `lei-aurea.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Document type:** The law is an `<act name="lei">`, with `FRBRsubtype` set to `lei` and `FRBRnumber` set to 3353.
- **Structure:** The title and summary are in `<preface>`. The enacting formula is a `<formula name="enactingFormula">` in `<preamble>`. The two articles are in `<body>`. The commands, date, signatures and Carta de Lei are in `<conclusions>`.
- **Translation:** The English is an attachment, a `<doc name="translation">` with `FRBRtranslation`. Claude wrote it for this edition. It is not an official text.
- **Highlight:** The words "a escravidão no Brazil" are in `<span class="landmark">`. The emphasis is editorial and is not in the source.
- **Colors:** Pink, green and gold follow the manuscript's use of color and are applied through the `class` attribute.
- **Identifiers:** Every element with an `eId` also has a `GUID`. Text-level `<p>` elements have neither.
- **Images:** The title, signatures and initial come from the manuscript. Browsers do not draw Akoma Ntoso `<img>` elements, so the CSS repeats them as backgrounds. The title and summary remain in the XML as text, and are hidden visually in favor of the image.

## Text and the manuscript

The Portuguese text is the Câmara dos Deputados text, character for character. It was not corrected or modernized. The images show the manuscript, which differs in places:

| Câmara text | Manuscript |
| --- | --- |
| Declara extinta a escravidão no Brazil. | Declara extincta a escravidão no Brasil |
| Art. 1º, Art. 2º | Artigo 1º, Artigo 2º |
| no Brazil (Article 1) | no Brasil |
| Majestade | Magestade |
| Sanccionou, sanccionar | sancionou, sancionar |
| Negocios da Agricultura | Negocios d'Agricultura |
| Transitou em 13 de Maio de 1888 | The day is hard to read and may be 12 or 13 |

This comparison was made by eye from the scan and may not be complete.

## Fonts

The stylesheet embeds Pinyon Script, Petit Formal Script and Old Standard TT, all licensed under the [SIL Open Font License](https://openfontlicense.org/). The script fonts approximate the manuscript's hand; they do not reproduce it, and line breaks differ from the original.
